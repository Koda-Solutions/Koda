# AGENTS.md

**Koda** frontend. Next.js 16 (App Router, Turbopack), React 19, TypeScript,
Tailwind v4. Live at https://www.kodasolutions.net.

**Every push to `main` deploys to production.** There is no staging.

## What Koda is

A self-serve store builder for non-technical Egyptian sellers who currently take
orders in Instagram DMs. They sign up with a phone number, get a shop at
`{slug}.kodasolutions.net`, and run it from one dashboard. Cash on delivery first,
because that is still how Egypt buys.

We compete on **design and trust**, not price or feature count. Wuilt is already free
here and EasyOrders already has more features; neither of those fights is winnable.
A previous version of this page was called AI-generated by a senior the owner
respects, which for a product selling trust is fatal. That is why the design rules
below are strict.

## Layout

```
src/app/                    routes, layout, globals.css
src/components/ui/          Button, Doodles, Rail, SketchUnderline
src/features/marketing/     the landing page
src/features/onboarding/    the wizard, plus api/ and plan.ts
src/context/                LanguageContext
src/data/                   content.ts (ALL copy), themePreviews.ts (the six themes)
src/lib/                    api/client.ts, utils.ts, color.ts, useCountUp.ts
```

A feature owns its own `api/` module. **Nothing calls `fetch` except
`lib/api/client.ts`.**

## The backend

Two Spring Boot services, `koda-identity-backend` (8081) and `koda-store-backend`
(8082). Every endpoint returns the same envelope:

```json
{ "message": "...", "status": true, "data": {}, "errorCode": null }
```

`status: false` is an expected business outcome, not a crash. `client.ts` turns it
into an `ApiError` carrying `errorCode`. **Switch on `errorCode`, never on `message`**:
the message is prose and it is translated.

**Read `effectiveTier`, never `tier`.** `tier` is what the merchant pays for and stays
`FREE` through a 14-day trial. `effectiveTier` is what they may do now, and
`availableThemes`, `teamSeats` and `maxProducts` all derive from it. Reading the wrong
one silently locks every paid feature away from trial users.

## Rules

1. **All copy in `src/data/content.ts`**, keyed `ar` then `en`. Never hardcode a
   visible string. The two blocks must stay structurally identical: TypeScript infers
   the type from the Arabic block, so a key missing from `en` is a build error and a
   key missing from `ar` is silently unavailable.
2. **Arabic is the default**, and the copy is **colloquial Egyptian**, not Modern
   Standard. "بيدج" not "صفحة". English is real English.
3. **Logical properties only**: `ms-`, `me-`, `ps-`, `pe-`, `start-`, `end-`. Never
   `ml-`/`left-`. Flip directional SVGs with `rtl:-scale-x-100`.
4. **Arabic never uses weight 600.** Thmanyah has no 600 face, so `font-semibold`
   synthesises and renders visibly thinner. Arabic headings use `font-black`.
5. **Caveat has no Arabic glyphs.** Annotations go through `handFont(language)` in
   `lib/utils.ts`, or they fall back to a system font silently. This has already
   happened once, to the logo wordmark.
6. **The server is the gate.** Show a limit as a hint; never enforce one. Always
   handle the server's refusal too, because a second tab exists.
7. **No em dashes.** Anywhere. Use a comma, a full stop, or a colon.

## Design

The look is deliberately hand-drawn: paper and ink plus six named marker colours,
wobbly borders from asymmetric `border-radius`, hard offset shadows with **no blur**,
sub-degree tilts, and line-art doodles in the space around content.

- `.sketch`, `.sketch-2`, `.sketch-3` wobbly borders. `.sketch-frame` for anything
  holding content, because the big radii crop corners.
- `.sketch-shadow` hard offset shadow. **Blur is the single most generated-looking
  thing in UI.**
- `.tilt-l` / `.tilt-r`, never on body text.
- `railClass()` / `railItem()` from `components/ui/Rail.tsx`: multi-card sections swipe
  on a phone and become a grid above the breakpoint. Keep the gap class unprefixed.

**Never**: warm cream + serif + one teal accent, uniform `rounded-lg` with an accent
bar, everything centred, purple-blue gradients, Inter or Space Grotesk, emoji as
section markers, soft blurred shadows, or SVG roughen filters (`feTurbulence` costs a
rasterise per repaint across thirty elements, which on a mid-range Android in Cairo is
exactly the latency this project cannot afford).

## Performance is a feature

A slow page on a cash-on-delivery storefront is an abandoned order, and the seller
paid for the ad either way.

- Scroll-triggered strokes use `animation-timeline: view()`, not IntersectionObserver.
- Counters share one `requestAnimationFrame` loop (`lib/useCountUp.ts`).
- Framer Motion for entrance and hover only. It was removed from `Button`, which was
  loading an animation runtime for a hover scale CSS does in one line.
- **Only declare a font weight something uses.** Every declared face is preloaded on
  every visit; 333KB was once shipped for weights nothing could display.
- Respect `prefers-reduced-motion`.

## React specifics

- **`useSyncExternalStore` for anything the server cannot see**, such as a URL query
  on a prerendered page. Not `useState` plus an effect: CI's
  `react-hooks/set-state-in-effect` rejects it.
- **No synchronous `setState` in an effect body.** Move it into a callback.
- **`useSearchParams` forces a Suspense boundary** on a statically prerendered route.

## Before you push

```bash
npx tsc --noEmit && npm run lint && npm run build
```

All three clean. CI runs exactly these. Then check the screen in **Arabic RTL and
English LTR**, in **light and dark**, at **mobile and desktop** widths.

## Local

```bash
npm install && npm run dev     # http://localhost:3000
```

Talks to `NEXT_PUBLIC_IDENTITY_URL` (default `http://localhost:8081`) and
`NEXT_PUBLIC_STORE_URL` (default `http://localhost:8082`). With no backend running,
set `NEXT_PUBLIC_API_FALLBACK=true` in `.env.local` to simulate the API. It is off by
default because on a public site it would tell a visitor their store is ready when it
was never created.
