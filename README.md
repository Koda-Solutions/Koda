# Koda Landing Page

Marketing site for **Koda** (كودا), a self-serve store builder for non-technical Egyptian sellers.

## Stack

- [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/) for animation
- Bilingual (Arabic default, English toggle) via a custom `LanguageContext`
- Arabic set in [Thmanyah Sans](https://font.thmanyah.com/) (خط ثمانية), English in Fraunces + Figtree

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm run start
```

Pushing to `main` deploys to [kodasolutions.net](https://www.kodasolutions.net/).
